# Changelog

## 1.1.0 — Preview

- Added Midnight mint, Amber terminal, Cyan lab and Violet spectrum themes.
- Added named instances with separate state, calibration and local ports.
- Added an IIS install page and ClickOnce manifests with startup update checks.
- Added PowerShell scripts for builds, publishing, dedicated IIS configuration,
  NTFS permissions and HTTPS/code-signing certificate enrollment.
- Verified HTTP and HTTPS delivery, application-pool permissions and download hashes
  against local IIS sites.

## 1.0.0 — Initial preview

- Rebuilt the cursor tracker as a self-contained .NET Windows executable.
- Added the local web dashboard, live telemetry console and equations.
- Added speed, timing, step-distance, movement and direction visualizations.
- Added a centred XY acceleration plot and activity gauge.
- Added session history, calibration, CSV export and browser installation assets.

Interactive ClickOnce install/upgrade testing and production signing remain open.

Install MouseTrail for Windows

Windows x64 · Version __VERSION__ · Runtime included

Install once. Keep up to date.

  1. Open this page in Microsoft Edge and select Install MouseTrail.
  2. If your browser downloads the deployment file, open it and follow Windows’ installation prompt. ClickOnce must be enabled by your organisation’s browser policy.
  3. Launch MouseTrail from the Start menu. Its dashboard opens locally.
  4. Optionally use Install app inside the dashboard for a separate browser window.

ClickOnce checks this installation location for updates before launching. Close MouseTrail before installing an update.

Your data stays with your instance

The website distributes application files. Tracking and history stay on your PC. Separate named instances keep separate settings and session histories.

The installed browser interface connects to the local Windows tracker, which must be running. MouseTrail’s self-contained .NET runtime needs no separate Python installation.

Preview deployment

This package is a preview. Your administrator can sign the deployment with a code-signing certificate before distribution. Windows trust prompts depend on that certificate and local policy.
